## 国际化
这是一个基于Next.js的个人网站项目。要实现国际化，我推荐使用Next.js官方支持的国际化解决方案 [next-intl](https://next-intl.dev/) 。下面是实现步骤：
1. 安装 next-intl 依赖
2. 创建语言文件（中文和英文）
3. 配置 Next.js 国际化设置
4. 创建语言切换组件
5. 调整项目结构以支持国际化路由
6. 创建国际化提供者组件
7. 修改布局文件
8. 修改导航栏和主页内容以使用翻译

实现后，您的网站将支持中英文切换，并且URL会反映当前语言（如 /zh/ 或 /en/ ）。用户可以通过语言切换按钮在中英文之间切换。
